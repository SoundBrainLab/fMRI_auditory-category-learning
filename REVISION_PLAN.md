# Revision Plan: Striatal 7T fMRI Auditory Category Learning Manuscript

## Context

The manuscript ("Distinct 7T functional MRI response patterns to stimulus and feedback across dorsal striatum during auditory learning") was rejected by *Journal of Neuroscience* after two rounds of revision (JN-RM-0379-25R2, decision 2026-08-16). Both reviewers' core complaint is not that the work is wrong, but that the manuscript **drifted across revisions**: RSA was cut, behavioral modeling (SPC vs. decision-bound models) and PFC connectivity were added late, and neither addition was well integrated with the paper's throughline or with each other. Reviewer #2 was largely positive about the two "core" results — the DWI structural-connectivity gradient and the univariate feedback/sound response profiles across striatal subregions — but flagged integration and reporting gaps. Reviewer #1 was more skeptical, doubting the feedback results would replicate at n=12, and identified a specific methodological flaw in the behavioral modeling (no direct model comparison, a structurally biased comparison, and a stimulus set — 16 stimuli — that's small relative to the decision-bound literature it's borrowed from).

**Decisions already made with the user:**
- Keep the behavioral (SPC/decision-bound) modeling — the user considers the method sound, but under-described and poorly integrated. Fix by writing it up properly *and* connecting it to the fMRI results, rather than removing it.
- Stay journal-agnostic for now (co-authors weighing in); candidates mentioned include *Neurobiology of Language*, *PLOS Biology*, and others. This plan is written to be venue-neutral — it fixes substance and integration, which matters regardless of where it's submitted. (Worth flagging honestly: *PLOS Biology* expects broad-significance framing that a confirmatory n=12 neuroimaging paper will struggle to hit without a substantial reframe; *Neurobiology of Language* or an SfN-family/specialty venue like *eNeuro* are likely easier fits given the reviews are about integration/rigor, not novelty of finding.)
- Open to new analyses beyond simple robustness checks, as long as they respect the n=12 constraint (no new data collection, no analyses that multiply comparisons without justification).

**Key repo findings that shape what's actually feasible:**
- The manuscript text itself lives outside any repo (Word/Overleaf) — this plan is a roadmap for what to change, not literal text edits.
- **The SPC/decision-bound modeling code does not exist anywhere in this repo or its git history.** It was run entirely outside this pipeline and never integrated. This is the first blocking item below.
- The HCP structural-connectivity work lives in a sibling repo, `/Users/dsj3886/software/hcp7t_mrtrix3_TianS2/`. Its README confirms this uses an **independent normative sample (up to 100 HCP 7T participants)**, not this study's own 12 participants — this validates Reviewer #1's "not unique to this study" critique and rules out any true within-subject structure↔function↔behavior individual-differences analysis. (Checked: this study's own `02_denoising/single_sub_dwi_denoise.sh` runs MRtrix3's `dwidenoise` on *functional* data as a denoising step, not on diffusion-weighted acquisitions — this study did not collect its own DWI. That option is off the table.)
- The "missing" striatum–PFC full ANOVA Reviewer #2 asked for is **already computed**: `hcp7t_mrtrix3_TianS2/connectivity_statistics.ipynb` → `stats_exports/anova_pfc_full.tsv`. It just isn't in the manuscript yet — a low-effort fix.
- Univariate fMRI stats (ANOVAs, FDR-corrected pairwise tests) live in `06_univariate/group_level_all_ROI.ipynb`, using the Tian-S2 8-ROI striatal parcellation (anterior/posterior caudate/putamen × hemisphere) + NAc, feeding up to 3–4-way repeated-measures ANOVAs off n=12 — consistent with both reviewers' power concerns.
- `07_rsa/` still exists in this repo even though RSA was already cut from the manuscript — no action needed unless the team wants to revisit it, which hasn't come up.
- No exact duplicate output files exist for the Fig 4C/3B issue — it's a manuscript-assembly error, not a pipeline bug.
- *(Historical, at the start of this work — fixed, see Progress below.)* All three GLM scripts in `06_univariate/` (`univariate_analysis.py`, `univariate_analysis_fb-correct-vs-wrong.py`, `univariate_groupedruns_analysis.py`) had aCompCor components explicitly commented out, kept only framewise displacement + 6 motion parameters as nuisance regressors, applied no motion scrubbing/censoring, and left noise model/drift model at nilearn defaults. fMRIPrep was pinned to 22.1.1 (Jan 2023). **Scope — headline claims only, not every ROI.** Checking robustness across all 8 Tian S2 ROIs × 2 hemispheres × 3 stages would recreate the exact multiple-comparisons problem these checks exist to counter. Primary target: the **anterior caudate vs. putamen feedback-response learning-stage interaction** (Table 8) — R2's explicit "anterior caudate decrease vs. sustained putamen" story, and the specific pattern R1 doubted would replicate. Table 5 (sound-related) is a secondary/optional extension using the same machinery if there's time.

**Summary scalar, reused rather than re-derived per check:** a per-subject linear learning-stage trend (contrast weights `[-1, 0, 1]` across early/middle/late feedback betas) per ROI, and the anterior-caudate-minus-putamen difference in that trend. This is the quantity the "decrease vs. sustained" claim actually rests on, and — worth noting — the same kind of per-subject scalar Workstream 1's SPC-model neural-linkage analysis needs (correlating learning trajectory with feedback response), so compute it once and reuse it rather than building it twice.

**Three checks on that scalar:**
1. **Leave-one-subject-out (LOSO) stability** — refit the group-level test 12 times, each excluding one subject; report how many of the 12 folds preserve the effect's direction and significance. A concrete, reportable answer to "would this replicate" — and if it flips when one particular subject drops out, better to know now than after resubmission.
2. **Permutation test as a supplement to (not replacement of) the existing parametric stats**, reporting both to show agreement. For pairwise pieces (e.g., early-vs-late, correct-vs-wrong), n=12 paired data admits an **exact sign-flip permutation test** (2^12 = 4096 combinations, fully enumerable — a genuine methodological upside of small n, not just a limitation) rather than a Monte Carlo approximation. For the full 3-level stage factor or any interaction, use Monte Carlo label-shuffling (~10,000 iterations) instead, since exact enumeration isn't practical there.
3. **Bootstrap 95% CI** on the effect size (the slope, or the anterior-caudate-minus-putamen slope difference) — resample the 12 subjects with replacement ~10,000 times, recompute the scalar each time, report a percentile or BCa CI. Standard way to defend an effect size without leaning on RM-ANOVA's normality/sphericity assumptions at n=12 — directly answers R2's comment that the exploratory pairwise testing needs justifying.

**Where this lives:**
- `06_univariate/group_level_all_ROI.ipynb` already builds the per-subject/per-ROI/per-stage beta dataframe feeding the existing AnovaRM/pairwise_tests calls. Export it partway through to `derivatives/nilearn/group_level/roi_values_long.csv` rather than duplicating that extraction logic — mirrors the QC-CSV pattern already introduced in `univariate_glm.py`.
- New script `06_univariate/robustness_checks.py`: loads that CSV, computes the trend/difference scalar, runs the three checks, and writes one summary table to `derivatives/nilearn/group_level/robustness_summary.csv` (per contrast: original parametric statistic, LOSO folds preserved, permutation p-value, bootstrap CI) — ready to drop into a manuscript table or a "Robustness of key results" paragraph.
- No new dependencies — `pandas`/`numpy`/`scipy` (already in `environment.yml`) cover it; LOSO/bootstrap/permutation are plain loops rather than a library call, which also makes the exact procedure easy to state precisely in Methods.

**Sequencing note:** can be prototyped now against the existing MNI-space ROI values (nothing here depends on the cluster) and re-run later against T1w-space values once Workstream 8 lands, if T1w ends up being what's reported.

**Explicitly ruled out:** expanding the connectivity analysis toward individual differences (no within-subject DWI exists — see Context), and adding further exploratory modeling/classifiers, which would only worsen the multiple-comparisons picture at this sample size. Also ruled out (see Workstream 0/1): model-recovery simulation for the behavioral models — requires model code that's assumed unavailable, so the 16-stimulus design gets a qualitative defense in the text instead.
